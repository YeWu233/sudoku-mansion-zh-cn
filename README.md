# Sudoku Mansion 简体中文汉化

《Sudoku Mansion》的非官方简体中文补丁，适用于 Steam Windows 版。

## 制作说明

本汉化补丁由 AI（OpenAI Codex）制作，包括文本翻译、补丁脚本与技术适配，并经过实际安装、游戏界面及还原流程测试。AI 翻译仍可能存在疏漏，欢迎通过 Issues 反馈问题。

## 汉化内容

- 剧情、房间名称与任务目标
- 数独规则、提示与教程
- 成就、弹窗与菜单界面
- 键盘和手柄操作说明
- 1.2.7 分别适配键鼠和手柄的操作教程，以及三处改写后的谜题规则

补丁安装程序只携带翻译数据和界面脚本，不包含游戏本体、谜题文件或美术资源。安装时会在玩家自己的正版游戏文件上应用翻译。

## 使用方法

1. 获取 `Sudoku-Mansion-zh-CN-1.2.7-zh-cn.1.zip`（已发布版本可在 [Releases](../../releases) 页面下载）。
2. 解压压缩包，确保 `patch` 文件夹与两个 PowerShell 脚本放在一起。
3. 完全退出《Sudoku Mansion》。
4. 右键 `安装汉化.ps1`，选择“使用 PowerShell 运行”。
5. 等待窗口显示“简体中文汉化安装完成”，然后从 Steam 正常启动游戏。

安装程序会自动查找 Steam 游戏目录、检查游戏版本与文件完整性，并在修改前备份英文原文件。不会修改存档。

如果 PowerShell 阻止脚本运行，可以在该文件夹打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装汉化.ps1
```

如果游戏装在无法自动识别的位置，可指定目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装汉化.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Sudoku Mansion"
```

## 恢复英文

完全退出游戏后，右键 `恢复英文.ps1` 并选择“使用 PowerShell 运行”。脚本会恢复安装汉化时自动保存的英文原版文件。

## Steam 更新后怎么办

Steam 更新或“验证游戏文件完整性”可能覆盖汉化。请先确认本仓库已经支持新的游戏版本，再下载对应版本的补丁。不要把 1.2.7 补丁强行安装到其他版本；安装程序会主动阻止这种操作。还原程序也会检查游戏版本，避免把旧版文件还原到新版游戏中。

## 常见问题

### 提示“原文件校验失败”

游戏文件可能已更新，或被其他模组修改。请在 Steam 中验证游戏文件完整性，再重新安装汉化。

### 安装后仍然显示英文

请完全退出所有《Sudoku Mansion》进程后重新启动。如果 Steam 刚刚更新过游戏，请查看仓库是否已有匹配的新补丁版本。

### 会影响存档吗？

不会。补丁只修改前端文本资源、默认庄园文本和界面加载入口，不读写玩家存档。
